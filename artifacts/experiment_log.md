# ARINC 429 实验记录

本记录由 `scripts/run_experiments.py` 生成，实验只在本地逻辑仿真器中运行，不连接串口、网络或任何真实航电设备。

- 模型文件 SHA-256：`ea80083df4b7fa1dc8374b9344bf3203b5d4c4a413a3a01b31d7f4b4dd6616be`
- Python：`3.14.7`
- 字长：`32` bit
- 仿真标签：`0o203`（合成测试标签）
- 仿真速率：`12500, 100000` bit/s

## 结果摘要

| 场景 | 原生接收端 | 受控网关 | 观测结论 |
|---|---|---|---|
| 未授权注入 | `True` | `False` / `unauthorized_source` | 原生端不识别来源；网关来源白名单生效 |
| 重放 | `True` | `False` / `replay` | 原生端无新鲜度；网关序号拒绝重复帧 |
| 重算奇偶后的篡改 | `True` | `False` / `authentication` | 奇偶校验仍为 `True`，但 MAC 不匹配 |
| 语义越界 | `True` | `False` / `semantic_range` | 原生端只做格式级检查；网关执行标签策略 |
| 连续占用 | `True`（超时） | `False`（未超时） | 入口过滤后合法帧在 `0.00` ms 开始发送 |
| 速率失配 | 接收端有效字：`False` | 端口配置控制 | `100000`→`12500` bit/s；字时长 `0.32`→`2.56` ms |
| 被动观测 | `data=1000` 可见 | 不由 MAC 提供保密性 | 若需保密，必须在受控边界增加加密/分区 |

## 复核要点

1. `legacy` 仅模拟奇偶校验和标签白名单，不能代表所有机载接收机实现。
2. `hardened` 的 MAC、序号和时间戳是系统级安全封装，不是原生 32 位 ARINC 429 字的新增字段。
3. 物理绕过受控入口的总线占用仍是残余风险，不能由接收端 MAC 单独消除；须依靠物理隔离、端口控制、故障遏制和架构级监测。
4. 单比特错误基线结果为 `parity_ok=False`；该校验用于传输错误检测，不等同于来源认证。
